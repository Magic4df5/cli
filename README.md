# CLI Log Analyzer

## Требования
Инструмент предназначен для службы поддержки с целью быстрого поиска частых ошибок, анализа уровней логирования и источников в многокомпонентных системах без загрузки больших файлов логов целиком в оперативную память

## Функционал
- Построчное чтение файлов логов для экономии памяти
- Сканирование формата `timestamp | level | source | eventCode | message`
- Проверка корректности временных меток ISO 8601 и допустимых уровней (`TRACE`, `DEBUG`, `INFO`, `WARN`, `ERROR`)
- Фильтрация по временному диапазону (начало включительно, конец исключительно) уровню и источнику
- Подсчет общего числа строк, валидных и ошибочных записей (с указанием точных номеров строк для ошибок)
- Генерация сводок по уровням и источникам
- Формат JSON и CSV

## Развертывание в WSL
1. Откройте проект в PyCharm через WSL-интерпретатор
2. Установите зависимости в терминале WSL:
   pip install -r requirements.txt

## Примеры использования CLI
Пример 1: анализ файла логов с выводом в терминал
python3 -m log_analyzer.cli --input logs_events_sample.log

Пример 2: Фильтрация по уровню ERROR и источнику payment-worker с выводом 3 частых ошибок
python3 -m log_analyzer.cli --input logs_events_sample.log --level ERROR --source payment-worker --top 3

Пример 3: Фильтрация по временному интервалу и сохранение отчета в JSON
python3 -m log_analyzer.cli --input logs_events_sample.log --from 2026-09-01T00:00:00Z --to 2026-09-02T00:00:00Z --format json --output report.json
